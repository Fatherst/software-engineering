# Платформа для фрилансеров

Система, которая напрямую связывает заказчиков с исполнителями-фрилансерами под конкретные задачи, когда нанимать сотрудника в штат нецелесообразно. Заказчик публикует заказ и выбирает исполнителя из откликов, фрилансер находит работу и пополняет портфолио. Оплата проходит внутри платформы с удержанием средств (escrow) до сдачи работы.

Проект по дисциплине «Программная инженерия». Документация проекта находится в папке `docs/`.
